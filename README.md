### 🌟 Featured Original Projects

#### 🏛️ [Kallpa Protocol](https://github.com/camesenin/kallpa-protocol)
> **Soroban multi-party funding and pro-rata settlement primitive for Trustless Work escrows on Stellar.**
* **Tech**: Rust, Soroban SDK, Stellar Testnet, GitHub Actions.
* **Architecture**: Implements decentralized, non-custodial milestone-based escrows with mathematical pro-rata distribution algorithms, invariant validation, and automated ledger TTL management.
* **Impact**: Engineered as a foundational financial primitive for the Stellar ecosystem and submitted to the Stellar Community Fund (SCF).
* 🔗 **Repo**: [camesenin/kallpa-protocol](https://github.com/camesenin/kallpa-protocol)

#### 🛡️ [SolAgent Sentinel](https://github.com/camesenin/solagent-sentinel)
> **Autonomous pre-flight security agent & AST firewall for Solana Actions (Blinks) and autonomous AI trading agents.**
* **Tech**: Rust, Solana Anchor, TypeScript, Next.js 14, Tailwind CSS, Vercel.
* **Architecture**: Deconstructs transaction Abstract Syntax Trees (AST) in memory to intercept malicious `SetAuthority` wallet drainers and unlimited token allowances before signing.
* **Performance**: Benchmarked at **0.028 – 0.038 ms** in-memory evaluation latency with zero false positives.
* 🌐 **Live Demo**: [solagent-sentinel.vercel.app](https://solagent-sentinel.vercel.app) | 🔗 **Repo**: [camesenin/solagent-sentinel](https://github.com/camesenin/solagent-sentinel)

#### 🏍️ [MotoECU](https://github.com/camesenin/MotoECU)
> **Real-time Bluetooth OBD-II automotive telemetry & ECU diagnostic dashboard for Android Auto.**
* **Tech**: Kotlin, Android Jetpack Compose, Android Auto Car App Library, Bluetooth Classic / BLE, Room SQLite, Coroutines.
* **Architecture**: Interfaces directly with motorcycle ECUs via ELM327 OBD-II protocols. Implements exponential moving average (EMA) noise filters and foreground services with SQLite trip logs.
* 🔗 **Repo**: [camesenin/MotoECU](https://github.com/camesenin/MotoECU)
